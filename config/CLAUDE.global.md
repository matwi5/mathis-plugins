# CLAUDE.md

Règles communes à tous les projets, rangées par plugin dans `config/rules/` du dépôt `mathis-plugins`. Ce fichier importe toutes ; `/setup:install` n'importe que celles des plugins choisis. Le `CLAUDE.md` d'un projet (et son `.claude/rules/`) l'emporte partout où il fixe sa propre convention.
