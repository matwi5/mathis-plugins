# Démarrage d'une session

Ce document est lu à partir de la section « Protocole de session » de `config/rules/project.md` (règles du plugin `project`, importées par le CLAUDE.md global) : ses règles valent comme si elles y étaient écrites. Le `CLAUDE.md` d'un projet l'emporte là où il fixe son propre protocole.

**Au démarrage** : lire dans `ETAT_DU_PROJET.md` la section « État » et les 5 premières entrées du « Journal » (les plus récentes ; le reste se consulte par recherche), puis le travail restant dans le suivi des tâches (règle « Suivi Asana »). Dans Asana : les tâches de la section du projet, puis les sous-tâches de chaque tâche mère, que la liste de la section ne renvoie pas. Le travail de Claude est sous la tâche mère non assignée « [code] <Projet> : prochaines sessions Claude Code » ; les tâches assignées à l'utilisateur sont les siennes.
